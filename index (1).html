AC-OPF-Based Stackelberg Framework for Cyber–Physical Attack Analysis in Power Systems

Research completedManuscript under review

Role: Lead Researcher · Systems: IEEE 14-bus and Kundur two-area · Platform: Python and RTDS NovaCor

This project combines AC optimal power flow (AC-OPF), Stackelberg optimization, and generator criticality assessment to evaluate the effects of false data injection and malicious generator outages. It examines how these disturbances affect grid operation and how to allocate limited protection resources.

Key Contributions

  • Developed an AC-OPF framework to quantify operational and economic impacts.
  • Used a defender–attacker Stackelberg model to evaluate protection resource allocation.
  • Assessed scenarios involving compromised load measurements and generator outages.
  • Developed a generator criticality index based on load shedding, voltage violations, line overloading, tie-line power transfer, and system inertia.
  • Evaluated selected cyber–physical disturbance scenarios in real-time simulations using RTDS NovaCor and Python.

Key Results

  • Worst-case operating cost increased from EUR 7,541.19 to EUR 19,742.49, approximately 161.8% above nominal operation.
  • The Stackelberg optimization identified a defense level of 0.90 for the reported case.
  • The criticality analysis ranked generating units by the operational consequences of their outages.
  • Real-time simulations assessed frequency deviations, generator power responses, and inter-area oscillations.

An Optimal Contingency-Sensitive Inertia and Damping Control for Grid-Forming Inverters

View paper Presentation (PDF)

Role: Co-Lead Researcher · Platform: RTDS NovaCor · System: IEEE 9-bus (IBR-only and hybrid grids)

This project uses a virtual synchronous machine (VSM) control framework for grid-forming inverters. The framework optimizes virtual inertia and damping offline for credible contingencies and adjusts both online through smooth, continuous-time gain modulation.

Key Contributions

  • Optimized virtual inertia and damping offline using differential evolution.
  • Implemented local, communication-free contingency detection in real time.
  • Used continuous-time modulation to transition smoothly between gains.
  • Validated the approach on inverter-only and hybrid grids using RTDS NovaCor.

Results & Impact

  • Improved the frequency nadir and reduced the rate of change of frequency (RoCoF).
  • Improved transient stability during inverter disconnection.
  • Outperformed droop, fixed VSM, and adaptive inertia controls in the tested scenarios.

Tools & Technologies

RTDS NovaCor · IEEE 9-bus · Grid-forming inverters · VSM · Differential evolution · Python · MATLAB

Optimal Adaptive Droop Control with AI-Based Contingency Detection for Frequency Regulation in Low-Inertia Power Systems

Ongoing Research · Skoltech

Role: Co-Lead Researcher · System: IEEE 39-Bus · Grid Type: Hybrid (synchronous generators and inverter-based resources)

This ongoing project develops adaptive droop control for low-inertia power grids with synchronous generators and inverter-based resources (IBRs). A data-driven classifier detects contingencies from electrical measurements and selects optimized droop gains for primary frequency regulation.

Key Contributions

  • Developed an IEEE 39-bus dynamic model and validated its response against RTDS simulations.
  • Integrated IBRs to study frequency regulation in hybrid-grid configurations.
  • Designed a data-driven contingency classifier using system-wide electrical measurements.
  • Optimized adaptive droop gains under eigenvalue-based stability constraints.
  • Connected contingency classification to real-time droop gain selection.

Preliminary Results

  • Reduced the frequency drop to the nadir during generator outages and load steps.
  • Reduced the rate of change of frequency (RoCoF) and accelerated frequency recovery in the tested hybrid-grid scenarios.
  • Improved frequency nadir and steady-state frequency deviation relative to standard droop control across the four benchmark cases shown.

A Measurement-Based Derivative Approach for Online Optimal Power Flow

Presented at IEEE PIERE 2026

Role: Co-Lead Researcher · System: Kundur two-area (11-bus) · Platform: Python and RTDS NovaCor

This project uses real-time measurements to calculate power flow derivatives for online AC optimal power flow. A Python-based primal–dual optimizer uses those derivatives to update generator setpoints in a closed loop with RTDS NovaCor.

Key Contributions

  • Built a closed-loop RTDS–Python framework for measurement-based online AC-OPF.
  • Implemented primal–dual optimization using real-time power flow Jacobians and Karush–Kuhn–Tucker (KKT) conditions.
  • Applied Kron reduction to retain four controllable generator buses from the original 11-bus network.
  • Applied a chain-rule correction to account for the eliminated load buses when calculating derivatives.
  • Introduced an angle stationarity correction to improve convergence.
  • Integrated TCP/IP communication through the RTDS GTNET interface to exchange measurements, Jacobians, and generator setpoints.

Key Results

  • Reduced the network from 11 to 4 buses, cutting full Jacobian entries per iteration from 484 to 64 (86.8%).
  • Brought all five monitored KKT residuals below 0.05 in 856 iterations, or about 71 minutes at a 5-second control interval.
  • Reduced online generation cost from $993,893.19/hr to $990,721.82/hr. The offline AC-OPF benchmark was $990,795.69/hr.
  • Compared with offline AC-OPF, the maximum generator active-power deviation was 1.85 MW and voltage-angle deviations stayed within 0.065°.
