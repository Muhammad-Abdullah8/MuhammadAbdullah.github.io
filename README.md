## GitHub Pages setup

Use this repository name for the personal website:

```text
Muhammad-Abdullah8.github.io
```

Then go to **Settings → Pages** and set:

```text
Source: Deploy from a branch
Branch: main
Folder: /root
```

Upload the extracted files, not the ZIP file.
